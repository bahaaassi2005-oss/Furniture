# Furniture Website

A modern and responsive furniture website designed using HTML5 and CSS3. The project showcases stylish furniture collections with a clean, user-friendly interface and fully responsive layout.

## Features

- Responsive Design
- Modern Home Page
- Product Categories
- Featured Furniture Section
- About Us Page
- Contact Form
- Image Gallery
- Smooth Navigation
- External CSS Styling
- Clean and Organized Code

## Technologies Used

- HTML5
- CSS3
- Visual Studio Code
- Live Server

## Project Structure

```text
Furniture/
│
├── index.html
├── about.html
├── products.html
├── gallery.html
├── services.html
├── contact.html
├── style.css
├── README.md
│
└── images/
```

## How to Run

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Run the project using Live Server.
